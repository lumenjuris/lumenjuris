# Captures pour la fiche AppSource (Partner Center)

Format exigé par Microsoft : PNG 1366 × 768. Les captures montrent le complément
réel (même code que la version publiée) avec une vraie analyse du contrat de
démonstration `Contrat-prestation-demo.docx` (sociétés fictives).

| Fichier | Légende (FR) | Caption (EN) |
|---|---|---|
| `1-ouvrir-lumen-juris-dans-word.png` | Ouvrez Lumen Juris depuis l'onglet Accueil de Word : le type de contrat est détecté automatiquement. | Open Lumen Juris from Word's Home tab: the contract type is detected automatically. |
| `2-clauses-a-risque-surlignees.png` | Lancez l'analyse : les clauses à risque sont surlignées directement dans votre document. | Run the analysis: risky clauses are highlighted directly in your Word document. |
| `3-detail-de-la-clause.png` | Cliquez sur une clause : elle est sélectionnée dans Word, avec les problèmes et une reformulation proposée. | Click a clause: it is selected in Word, with the issues found and a suggested rewrite. |
| `4-revision-suivi-des-modifications.png` | La reformulation est insérée en suivi des modifications : acceptez-la ou refusez-la dans l'onglet Révision. | The rewrite is inserted as a tracked change: accept or reject it from Word's Review tab. |
| `5-question-a-l-ia-sur-la-clause.png` | Posez une question sur la clause sans quitter Word. | Ask the AI a question about the clause without leaving Word. |
